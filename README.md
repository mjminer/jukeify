# Jukeify

A Minecraft jukebox interface for controlling Spotify.

## Targets

- Forge 1.20.1 — primary target for Jaffa Factory 2
- Fabric 1.21.4 — planned
- Forge 26.3 / 66.0.6 — planned

## Current milestone

V0.2-dev

- Empty-jukebox right click opens the Jukeify interface.
- Music discs keep normal vanilla behaviour.
- Shift + right click bypasses Jukeify.
- Spinning vinyl UI prototype with an album-art centre.
- Common entrypoint remains server-safe so the same mod can later be installed client-only or on both client and server.
- Spotify OAuth/PKCE and real playback controls come next.

This project is under active development and is not yet a finished public release.
